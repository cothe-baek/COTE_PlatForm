# 숫자 카드

## 문제
N개의 숫자 카드를 가지고 있다. M개의 정수에 대해 그 수가 적힌 카드를 가지고 있는지 판별한다.

## 입력
첫째 줄에 N (1 ≤ N ≤ 100,000), 둘째 줄에 카드에 적힌 정수 N개, 셋째 줄에 M (1 ≤ M ≤ 100,000), 넷째 줄에 판별할 정수 M개가 주어진다. 모든 정수의 절댓값은 10^7 이하이다.

## 출력
각 정수에 대해 카드를 가지고 있으면 1, 아니면 0을 공백으로 구분해 출력한다.
