# 최댓값과 위치

## 문제
N개의 정수가 주어진다. 최댓값과 그 값이 처음 등장하는 위치(1부터 시작)를 출력한다.

## 입력
첫째 줄에 N (1 ≤ N ≤ 100,000), 둘째 줄에 N개의 정수가 공백으로 구분되어 주어진다. 각 정수의 절댓값은 10^9 이하이다.

## 출력
최댓값과 위치를 공백으로 구분해 출력한다.
