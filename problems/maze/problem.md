# 미로 탐색

## 문제
N×M 크기의 미로가 주어진다. 1은 이동할 수 있는 칸, 0은 이동할 수 없는 칸이다. (1,1)에서 출발하여 (N,M)에 도착할 때 지나야 하는 최소 칸 수를 구한다. 시작 칸과 도착 칸도 센다. 상하좌우로만 이동할 수 있다.

## 입력
첫째 줄에 N, M (1 ≤ N, M ≤ 100), 이후 N개의 줄에 M개의 숫자가 붙어서 주어진다. (1,1)과 (N,M)은 항상 1이다.

## 출력
최소 칸 수를 출력한다. 도착할 수 없으면 -1을 출력한다.
