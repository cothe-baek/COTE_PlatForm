# 가장 긴 증가하는 부분 수열

## 문제
수열 A에서 가장 긴 증가하는 부분 수열의 길이를 구한다.

## 입력
첫째 줄에 N (1 ≤ N ≤ 100,000), 둘째 줄에 수열 A의 원소 N개 (1 ≤ A_i ≤ 1,000,000)가 주어진다.

## 출력
가장 긴 증가하는 부분 수열의 길이를 출력한다.
