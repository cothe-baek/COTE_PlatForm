# 동전 최소 개수

## 문제
N종류의 동전으로 K원을 만들 때 필요한 동전 개수의 최솟값을 구한다. 각 동전의 가치는 바로 앞 동전 가치의 배수이다.

## 입력
첫째 줄에 N (1 ≤ N ≤ 10)과 K (1 ≤ K ≤ 100,000,000), 이후 N개의 줄에 동전의 가치가 오름차순으로 주어진다. 첫 번째 동전의 가치는 항상 1이다.

## 출력
동전 개수의 최솟값을 출력한다.
