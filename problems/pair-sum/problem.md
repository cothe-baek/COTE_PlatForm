# 두 수의 합 세기

## 문제
서로 다른 N개의 정수 중 두 개를 골라 합이 M이 되는 경우의 수를 구한다.

## 입력
첫째 줄에 N과 M (2 ≤ N ≤ 100,000, -10^9 ≤ M ≤ 10^9), 둘째 줄에 서로 다른 N개의 정수가 주어진다. 각 정수의 절댓값은 10^9 이하이다.

## 출력
합이 M이 되는 쌍의 개수를 출력한다.
