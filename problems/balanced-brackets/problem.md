# 괄호 균형

## 문제
`()`, `[]`, `{}` 세 종류의 괄호로 이루어진 문자열이 올바른 괄호 문자열인지 판별한다. 여는 괄호는 같은 종류의 닫는 괄호와 올바른 순서로 짝을 이뤄야 한다.

## 입력
첫째 줄에 테스트케이스 수 T (1 ≤ T ≤ 100), 이후 T개의 줄에 길이 1 이상 10,000 이하의 괄호 문자열이 주어진다.

## 출력
각 문자열에 대해 올바르면 `YES`, 아니면 `NO`를 출력한다.
