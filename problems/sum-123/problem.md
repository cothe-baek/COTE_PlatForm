# 1, 2, 3 더하기

## 문제
정수 n을 1, 2, 3의 합으로 나타내는 방법의 수를 구한다. 합을 이루는 수의 순서가 다르면 다른 방법으로 센다.

## 입력
첫째 줄에 테스트케이스 수 T, 이후 T개의 줄에 정수 n (1 ≤ n ≤ 11)이 주어진다.

## 출력
각 테스트케이스마다 방법의 수를 출력한다.
