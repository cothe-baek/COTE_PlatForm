# 회의실 배정

## 문제
회의실 하나를 N개의 회의가 사용하려 한다. 각 회의의 시작 시간과 끝나는 시간이 주어질 때, 겹치지 않게 진행할 수 있는 회의의 최대 개수를 구한다. 회의가 끝나는 시간과 다음 회의가 시작하는 시간이 같아도 된다.

## 입력
첫째 줄에 N (1 ≤ N ≤ 100,000), 이후 N개의 줄에 시작 시간과 끝나는 시간이 주어진다. (0 ≤ 시작 ≤ 끝 ≤ 2^31-1)

## 출력
최대 회의 개수를 출력한다.
