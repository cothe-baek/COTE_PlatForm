# 나이순 정렬

## 문제
회원 N명의 나이와 이름이 가입 순서대로 주어진다. 나이가 증가하는 순으로, 나이가 같으면 먼저 가입한 사람이 앞에 오도록 정렬해 출력한다.

## 입력
첫째 줄에 N (1 ≤ N ≤ 100,000), 이후 N개의 줄에 나이(1 이상 200 이하의 정수)와 이름(알파벳, 길이 100 이하)이 공백으로 구분되어 주어진다.

## 출력
정렬된 순서대로 각 줄에 나이와 이름을 공백으로 구분해 출력한다.
