# 평범한 배낭

## 문제
N개의 물건이 있고 각 물건은 무게 W와 가치 V를 가진다. 최대 K 무게까지 담을 수 있는 배낭에 물건을 넣을 때 가치의 최댓값을 구한다.

## 입력
첫째 줄에 N (1 ≤ N ≤ 100)과 K (1 ≤ K ≤ 100,000), 이후 N개의 줄에 각 물건의 무게 W (1 ≤ W ≤ 100,000)와 가치 V (0 ≤ V ≤ 1,000)가 주어진다.

## 출력
가치의 최댓값을 출력한다.
