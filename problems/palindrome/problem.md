# 회문 판별

## 문제
문자열이 앞에서 읽어도 뒤에서 읽어도 같으면 회문이다. 각 문자열이 회문인지 판별한다.

## 입력
첫째 줄에 문자열의 개수 T (1 ≤ T ≤ 100), 이후 T개의 줄에 알파벳 소문자로 된 문자열(길이 1 이상 100 이하)이 주어진다.

## 출력
각 문자열에 대해 회문이면 `yes`, 아니면 `no`를 한 줄씩 출력한다.
