# 요세푸스 순열

## 문제
1번부터 N번까지 N명이 원을 이루어 앉아 있다. 1번부터 시작해 K번째 사람을 제거하고, 그 다음 사람부터 다시 K번째 사람을 제거하는 과정을 모두 제거될 때까지 반복한다. 제거되는 순서를 출력한다.

## 입력
첫째 줄에 N과 K가 주어진다. (1 ≤ K ≤ N ≤ 5,000)

## 출력
제거되는 순서를 공백으로 구분해 출력한다.
