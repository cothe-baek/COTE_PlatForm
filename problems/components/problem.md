# 연결 요소의 개수

## 문제
방향 없는 그래프가 주어졌을 때 연결 요소(connected component)의 개수를 구한다.

## 입력
첫째 줄에 정점의 개수 N (1 ≤ N ≤ 1,000)과 간선의 개수 M (0 ≤ M ≤ N(N-1)/2), 이후 M개의 줄에 간선의 양 끝점 u, v가 주어진다.

## 출력
연결 요소의 개수를 출력한다.
