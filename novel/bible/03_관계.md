# 03. 관계

> 수치 범위: **호감도 -100(살의) ~ 0(무관심) ~ +100(절대 신뢰/연정)**.
> 표기는 "A→B" (A가 B를 보는 수치). 회귀 직후(412년 3월 2일) 기준 **초기치**.
> 기록 에이전트는 매 화 PASS 후 "현재치"를 갱신하고 변동 사유를 아래 '변화 로그'에 추가한다.

## 2. 관계 변화 예정 계기 (아크별 상세)

### 아크 1 (1~12화)
- **카일↔가족**: 3화 로렌스에게 목검으로 공개 망신 + 에드먼드와 대련 승리 → 가족 전체가 "쟤 뭐지?". 4화 한스가 낙인을 발견하고 침묵(+경외, 비밀 편지 복선). 6화 세실리아의 기침 소리를 카일이 듣고 굳는다(+짠함). 11화 고블린 왕의 굴 금화 1,200닢으로 채무 일부 상환 → 레오나르가 처음으로 카일의 눈을 본다.
- **카일↔오스왈드**: 5화 카일이 흑아검 1식을 쓰다 오스왈드에게 발각 → "어디서 훔쳤냐" → 7화 카일이 "당신 유골 옆에서 배웠다"고 진실의 반만 말함("어머니가 남긴 책"이라 둘러댐) → 8화 제자 인정.
- **카일↔발타자르**: 4화 채무 독촉 사자 방문에서 카일이 처음으로 맞선다(사자의 보고로 -10→-25). 9~10화 고블린 왕의 굴 선점 → 발타자르의 '관찰 대상' 등재(-40).
- **카일↔루카스**: 12화 수석 발표식에서 첫 대면. 루카스의 "시험관 눈이 없나" → 카일 "전하 눈이 없으신 거겠지요"(속마음, 입 밖엔 "영광입니다") → 루카스 견제 시작.

### 아크 2 (13~25화)
- **카일↔리젤**: 13화 입학식 날 리젤의 어깨 버릇 지적 → 리젤 "너 뭐야" → 16화 공개 대련, 카일 승(1회차 지식+흑아검) → "다음엔 내가 이긴다. 약속해." → 사실상 첫 '친구'(카일은 그 단어를 안 씀).
- **카일↔아델라이드**: 15화 카일이 A동 1인실 배정(수석) → 아델라이드 "설명해" → 17화 데릭과의 결투에서 데릭을 공개 박살 → 아델라이드의 관심(0). 20화 폐허의 탑 공간 주머니 선점 → 아델라이드 -40(분노) → 21화 카일이 주머니 안의 '고대 마법서'를 그녀에게 넘기며 "나는 못 읽어. 너는 읽겠지" → +25.
- **카일↔엘레나**: 14화 신학부 오리엔테이션에서 스침(엘레나가 넘어질 뻔한 걸 카일이 잡고 "…반지, 끼지 마"라고 혼잣말—엘레나 +20, 의문) → 22~24화 침묵의 호수 유적 선점, 23화 정화의 반지를 카일이 먼저 획득 → 엘레나에게 "각인 없는 반지"로 건넴 → +45.
- **카일↔테오**: 13화 D동이 아닌 A동이라 테오와 룸메이트 안 됨(1회차와 다름). 테오가 먼저 접근. 카일 속마음 -100, 겉으론 무관심. 18화 테오가 카일의 점심에 끼어들고, 카일이 "…앉아"라고 허락(감시 목적) → 독자에게 긴장.
- **카일↔라자루스**: 25화 황실 재무대신으로서 아카데미 방문, 카일과 첫 대면. 카일은 살의를 참는다(코피=낙인 부작용 아님, 분노). 라자루스 "아버님과 황궁에서 뵌 적이".
- **카일↔마르셀**: 12→19화 마나 측정 재검, "봉인"이라는 단어. 카일 "…봉인?"(카일도 모름). 복선.

### 아크 3 (26~40화)
- **카일↔가문**: 영지 위기(가뭄+채무 만기) → 카일의 미래 지식(검은 입 은광, 피오나의 연금술 비료) → 29화 레오나르가 검을 다시 든다(+85). 33화 로렌스의 정보 유출 발각 → 세실리아 "나가" → 추방. 35화 세실리아 정략결혼 통보 → 카일이 결혼식 전날 모르간 사촌을 결투로 박살.
- **카일↔아델라이드**: 30화 귀족파 자금(금화 2,000닢) 투자 제안을 아델라이드가 직접 들고 온다. "투자야. 호의가 아니고." → +50. 38화 단 한 번 "카일"이라 부름.
- **카일↔발타자르/하인리히**: 36~39화 전면전. 39화 하인리히 vs 카일 1차 교전—카일 패배 직전 오스왈드 등장. 40화 402년 밀서 조작 증거(한스의 장부+로렌스의 자백+레오나르의 고백) → 황실 재판 → 발타자르 작위 박탈.
- **카일↔레오나르**: 40화 끝, "그 밀서는 네 어머니에게 온 것이었다." 카일의 세계가 흔들린다.

### 아크 4 (41~60화)
- **카일↔루카스**: 44~47화 제1황자 독살 저지 공동 작전 → "카일 아스트리드"(풀네임) → 60화 "카일".
- **카일↔엘레나**: 51~53화 베네딕트 납치 시도 저지 → 엘레나가 후견인의 정체를 알고 무너짐 → 카일 "너는 성녀 후보가 아니라 엘레나야" → +85. 엘레나가 세실리아를 치유.
- **카일↔테오**: 55~57화 테오가 「회색 쥐」로 카일 앞에 선다 → 카일이 리나의 죽음(교단의 환영)을 폭로 → 테오 붕괴 → 58화 테오가 교단을 배신, 가면을 내려놓는다. 카일: "…친구라고는 안 한다. 아직." (+40)
- **카일↔리젤**: 59화 1차 결전에서 리젤 왼팔 부상 위기 → 카일이 찰나 되감기로 구함 → 리젤 "너… 방금 뭐 했어?" → 카일이 처음으로 "친구니까"라고 말한다(테오가 아닌 리젤에게). +95.
- **카일↔하인리히**: 59화 카일 소드 마스터 각성 + 오스왈드 협공 → 처단.
